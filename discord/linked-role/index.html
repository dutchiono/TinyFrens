Connect the account you already use

TinyFrens does not create a playable account when you join a Discord Scrap Run. Connect Discord explicitly so your NFTs, selections, and game rewards stay with the same account you use on web, Android, desktop, or Telegram.

How to link Discord

Open TinyFrens Account and create a code under Sync devices. In Discord, run /link code:YOUR-CODE. Return to the original TinyFrens device and approve the request.
