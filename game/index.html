THE CURRENT LOOP

One command, four steps.

  1. 01

    Open the run

    Use /game in a group or channel. If a run is already open, the bot refreshes that run instead of creating a second one. Starting a run does not automatically join you.

  2. 02

    Link, then join the crew

    Connect Telegram or Discord to your existing TinyFrens account with /link, then press Join crew while the run is open. The bot never creates a hidden playable account just because you join.

  3. 03

    Search right away

    Any joined crew member can press Search scrap immediately. There is no waiting period; other players can join until somebody searches. Only a crew member can resolve the run.

  4. 04

    Share the find

    The bot rolls one piece of loot for the entire crew. Everyone receives the same rarity and the same individual game-credit reward, including the crew-size bonus.

GOOD TO KNOW

Same game, quiet chat.

No chat lock

The group stays open for normal conversation. The bot edits one run card as people join and replaces it with the result, keeping the run from becoming message spam.

Same engine, separate rooms

Telegram and Discord use the same rules, loot table, reward logic, and database code. Each group or channel keeps its own run so unrelated communities never overwrite each other.

One account, explicitly linked

Discord and Telegram must be connected with /link before joining. Once approved, the platform identity belongs to the same TinyFrens account and uses its shared wallets and companion selections.

Credits are not FRENS or Energy

The current Scrap Run awards off-chain game credits. It does not mint or transfer FRENS, and joining a run does not spend Robots v1 Energy. Those economy systems remain distinct.

Separate from solo arcade games

Snack Catch and other app games are short solo modes with NFT players. They are not another version of the group Scrap Run.

Built for iteration

This is the foundation loop. Loot, balance, events, and additional crew decisions can evolve once real groups test it—without creating separate Telegram and Discord games.
