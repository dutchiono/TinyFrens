23 hours later: the backend migration is done

We went dark for 23 hours while we finished a migration that got much bigger than expected. That part is on us. We should’ve said something sooner.

TinyFrens is now fully running on Node 22 and TypeScript in production. No Python service is sitting behind the app anymore.

What changed

  • 36 migration and closeout pull requests landed.
  • 416 TypeScript tests now cover the server.
  • Every client route and all 50 production database tables are inventoried.
  • We ran shadow traffic, a canary, rollback drills, contract-event integration, and live production checks.
  • The deployed JavaScript matches the build from main byte for byte.

Why it took so long

We treated this like a production migration instead of a file-extension swap. Wallets, ownership checks, deposits, Telegram, WebSockets, mobile clients, desktop clients, and the existing SQLite data all had to keep behaving the same way.

We also found unrelated old services crowding the server. Those are gone now. TinyFrens itself is steady at about 100 MB with no restart loop.

What happens next

Smaller releases. Clearer updates. Less going quiet while we wrestle the machinery.

Thanks for sticking around. Your frens are back, the backend is lighter, and we’ll use this page to keep you in the loop from here on out. 💜
