# TinyFrens play and effects

## Available now

Windows and Mac have a native floating pet with care bubbles, dragging, roaming, a close button and shared desktop saves.

Companion display settings provide 40–100% NFT opacity, sparkles, gentle care glow, fade and Reduce motion without changing NFT artwork or traits. Android and desktop overlays show effects near the companion; web/native iOS show them inside the app. Effects are cosmetic, brief and do not change care rewards.

## More screen effects — planned

Weather, richer action-specific confetti/stars and arrival/goodbye effects. Preserve the off switches, reduced motion and click-through areas. iOS cannot draw these above arbitrary apps.

## Objects — planned

Beds for naps, bowls for food and toys for play. Objects must trigger existing Feed/Play/Nap rules with the same costs, caps, animations and feedback. No hidden rewards from dragging/catching objects. The Android toy chase already exists; desktop has a cosmetic toy beside the pet, with a moving chase still planned.

## Nearby friends

Native Bluetooth/Wi-Fi discovery should find a friend's server code and enter the existing friendship/visit consent flow. No automatic uninvited visits. Requires native SDK integration, permissions and tests on two phones; the relay is built. Visitors currently appear inside the care app rather than as floating guests.

## On-chain economy — planned

Per-fren Bankr wallets, FRENS credit deposits (rotating receive addresses + deposit sessions), in-world jackpot finds, and UUPS proxy contracts on testnet before any mainnet deploy. See [ONCHAIN-ECONOMY.md](./ONCHAIN-ECONOMY.md).
