## Quick map of the repo

```
web/        Shared pet UI (PWA) — runs in web, Telegram &amp; Farcaster
android/    Native Android floating-overlay pet (Kotlin)
desktop/    Windows/Mac floating pet (Electron)
ios/        Native iOS shell + widget
server/     Live friends / party relay + chat + Bankr + Telegram/Discord (aiohttp)
site/       Welcome / marketing page
contracts/  On-chain contracts + FRENS economy (Solidity, Foundry)
docs/       You are here
```
