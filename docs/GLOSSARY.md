# Glossary

| Term | Definition |
|---|---|
| **Net Protocol** | Decentralized, content-addressed storage used for TinyFrens assets/metadata. Files identified by CID; verifiable and portable. See [Storage](STORAGE.md). |
| **CID** | Content Identifier (hash) used in content-addressed systems like Net Protocol. Changing content changes CID. |
| **FREN** | On-chain token in TinyFrens economy ([ONCHAIN-ECONOMY.md](../ONCHAIN-ECONOMY.md)). |
| **ERC721A** | Gas-efficient ERC721 implementation. Extended by `NetIntegratedERC721A`. |
| **NetIntegratedERC721A** | Custom ERC721A variant with Net Protocol integration for URI/asset references. |
| **Party room** | Shared space where frens hang together ([Party rooms](party-rooms.md)). |
| **Visit** | Drop-in to see another fren's companion. |
| **Care loop** | Core tamagotchi actions: Feed/Play/Nap/Clean/Vitamin. |
| **Bankr** | Wallet connection flow used in app/Telegram to link accounts via read-only signature. |
| **Overlay (Android)** | Floating pet that can appear on top of other apps. |
| **PWA** | Progressive Web App (`web/`) — runs in browser, Telegram Mini App, Farcaster. |
| **Read-only signature** | Signature proving wallet ownership without transferring tokens or spending gas. |
| **TinyFrensNFT/Art/Sprite** | Custom contracts for NFT/art/sprite logic. See [Contracts](CONTRACTS.md). |
| **Tamagotchi** | Care-based virtual pet — core inspiration for TinyFrens. |
| **RPG (planned)** | Quests/adventures/items/progression planned for future ([Game &amp; RPG](GAME.md)). |
