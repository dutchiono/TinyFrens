# How To

Quick answers for common tasks. For deep technicals, see [full docs](README.md).

## Getting started

- **Web**: Open [tinyfrens.lol/web](https://tinyfrens.lol/web) and connect your wallet/Bankr.
- **Telegram**: Start [@TinyFrensBot](https://t.me/TinyFrensBot?start=connect).
- **Android**: [Download APK](https://github.com/dutchiono/TinyFrens/releases/latest/download/pocket-familiar.apk), install, grant "Display over other apps", then show pet.
- **Desktop (Windows/Mac)**: Get builds from [releases](https://github.com/dutchiono/TinyFrens/releases) (Windows `.exe`, Mac arm64/x64 `.zip`).
- **iOS**: Open in Safari → Share → Add to Home Screen. Native App Store release coming later.

## Playing

- **Care**: Feed fills Food. Play makes happy. Nap gives energy. Clean/Vitamin when needed.
- **Fun**: Wave, dance, put out a toy.
- **Visits**: Drop in on other frens (when connected).
- **Party rooms**: Hang with multiple frens together ([Party rooms](party-rooms.md)).
- **Games**: Try mini-games in app (see Games tab).

## Linking &amp; sync

- **Bankr pairing**: App shows temporary pairing code → give to Bankr → Bankr signs read-only message → approve on device. Device credential never enters chat.
- **What syncs**: Linked devices share wallets, shown NFTs, size/movement, display name, linked socials. Device credentials stay private.
- **Ownership**: Checked on connect, renewed every 24 hours. Selling NFT stops display after next check (needs internet).

## Storage &amp; tech

- **Net Protocol**: All assets/metadata stored via Net Protocol (content-addressed). See [Storage](STORAGE.md).
- **Your NFTs stay yours**: We only ask for read-only signatures — no transfers, approvals, or gas.

## Safety &amp; updates

- **Updates**: Use in-app update prompt or latest GitHub release. Reopen after updating.
- **Local saves**: Saves stay on device. Uninstalling/clearing data can remove save.
- **Android**: May need to re-grant overlay permission after some updates.

## Troubleshooting

- **Can't float (Android)**: Enable "Display over other apps" for TinyFrens, then reopen/show pet.
- **iOS overlay**: iOS keeps frens inside app for now; native floating overlay not available. Home-screen app works.
- **Connection issues**: Ensure internet for ownership checks/party; local pet still visible until check expires.
- **Stuck**: Force restart app, update to latest, re-link if needed.

For more, see [FAQ](FAQ.md) and [full docs](README.md).
